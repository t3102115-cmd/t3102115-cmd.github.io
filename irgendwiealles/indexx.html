Lade Spielerdaten...

Spielerdaten werden aus der players.json Datei geladen. Um Spieler hinzuzufügen oder zu bearbeiten, bearbeite diese Datei im GitHub Repository.

Konfigurationsanleitung

Spieler werden über die players.json Datei verwaltet:

  1. Öffne die players.json Datei in deinem GitHub Repository
  2. Bearbeite die Spielerliste im JSON-Format
  3. Jeder Spieler benötigt: name, date (TT.MM.JJJJ), time (HH:MM)
  4. Änderungen werden automatisch nach dem nächsten Refresh übernommen

Beispiel:
"name": "Steve", "date": "22.01.2026", "time": "18:30"
